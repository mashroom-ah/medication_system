# Система учёта лекарств

## Назначение

Приложение помогает пользователям контролировать приём лекарственных препаратов: позволяет создавать профиль, добавлять препараты, устанавливать расписание приёма и отслеживать фактические приёмы лекарств.

## Целевая аудитория

Люди, принимающие лекарства по расписанию, а также их опекуны.

## Предметная область

Персональный учёт и контроль приёма лекарственных препаратов пользователем. Включает регистрацию пользователя, добавление препарата с дозировкой, установку времени приёма, проверку текущего времени относительно расписания и фиксацию факта приёма.

В ПР2 программа расширена для работы с несколькими пользователями, препаратами, расписаниями и записями о приёмах. Данные сохраняются в JSON-файлах.

## Основные сущности

- `User` — пользователь. Атрибуты: `id`, `name`, `age`. Методы: `__init__`, `__str__`, `from_data`, `to_data`.
- `Medicine` — лекарственный препарат. Атрибуты: `id`, `name`, `dosage`, `unit`. Методы: `__init__`, `__str__`, `validate_dosage`, `from_data`, `to_data`.
- `Schedule` — расписание приёма. Атрибуты: `id`, `user`, `medicine`, `hour`, `minute`. Методы: `__init__`, `__str__`, `validate_time`, `is_due`, `get_status`, `from_data`, `to_data`.
- `Intake` — запись о факте приёма. Атрибуты: `id`, `schedule`, `date`, `taken`. Методы: `__init__`, `__str__`, `cancel`, `from_data`, `to_data`.

Объекты `Schedule` хранят ссылки на `User` и `Medicine`, а `Intake` — ссылку на `Schedule`. Благодаря этому объекты взаимодействуют между собой, а функции модулей работают с коллекциями объектов, а не со словарями.

Для создания объектов из JSON используются методы классов `from_data()` с декоратором `@classmethod`. Для проверок, не зависящих от конкретного объекта, используются статические методы `@staticmethod`.

## Основные функции

* `add_user()` – добавление пользователя.
* `find_user()` – поиск пользователя.
* `sort_users()` – сортировка пользователей.
* `add_medicine()` – добавление препарата.
* `find_medicine()` – поиск препарата.
* `filter_medicines_by_dosage()` – фильтрация препаратов по дозировке.
* `sort_medicines()` – сортировка препаратов.
* `add_schedule()` – добавление расписания приёма.
* `is_schedule_due()` – проверка наступления времени приёма.
* `get_schedule_status()` – получение статуса приёма.
* `sort_schedules()` – сортировка расписаний.
* `create_intake()` – создание записи о фактическом приёме.
* `is_medicine_taken()` – проверка факта приёма за указанную дату.
* `cancel_intake()` – отмена записи о приёме.
* `get_intakes_by_date()` – получение записей о приёмах за указанную дату.

## Возможности

- добавление и поиск пользователей;
- сортировка пользователей по возрасту;
- добавление, поиск, фильтрация и сортировка лекарств;
- создание и просмотр расписаний приёма;
- проверка наступления времени приёма;
- фиксация приёма лекарства;
- отмена записи о приёме с сохранением истории;
- просмотр приёмов за выбранную дату;
- загрузка и сохранение данных в JSON.

## Хранение данных

JSON используется как формат постоянного хранения. В приложении данные представлены объектами классов.

В `schedules.json` сохраняются `user_id` и `medicine_id`, а в `intakes.json` — `schedule_id`. При запуске программы `storage.py` загружает JSON и восстанавливает связи между объектами.
