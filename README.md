# Система учёта лекарств

## Назначение
Приложение помогает пользователям контролировать приём лекарственных препаратов: позволяет заводить профиль, добавлять препараты, устанавливать расписание приёма и отслеживать, принято ли лекарство вовремя.

## Целевая аудитория
Люди, принимающие лекарства по расписанию (например, пациенты с хроническими заболеваниями, пожилые люди), а также их опекуны.

## Предметная область
Персональный учёт и контроль приёма лекарственных препаратов одним пользователем. Включает регистрацию пользователя, добавление препарата с дозировкой и минимальным возрастом, установку времени приёма, проверку текущего времени относительно расписания, а также фиксацию факта приёма. На текущем этапе область ограничена консольным сценарием без постоянного хранения данных и многопользовательского взаимодействия.

## Основные сущности
- **Пользователь** – имя, возраст.
- **Препарат** – название, дозировка, единица измерения, минимальный возраст (для демонстрации).
- **Расписание** – время приёма (час, минута).
- **Приём** – факт принятия препарата (булево значение).

## Основные функции (реализованы на ПР1)
- `create_user(name, age)` – создание записи пользователя.
- `create_medicine(name, dosage, unit)` – создание записи препарата.
- `create_schedule(hour, minute)` – создание расписания.
- `check_schedule()` – проверка, наступило ли время приёма и не принят ли уже препарат.
- `take_medicine()` – фиксация факта приёма.

## План развития
- Переход к объектно-ориентированной модели (классы User, Medicine, Schedule, Dose).
- Подключение базы данных (SQLite / PostgreSQL) для хранения данных.
- Реализация веб-интерфейса на Django.
- Добавление авторизации пользователей.
- Разработка REST API.
- Контейнеризация с помощью Docker.
